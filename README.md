# DSA - LeetCode & HackerRank Solutions in Java

[![Ask DeepWiki](https://devin.ai/assets/askdeepwiki.png)](https://deepwiki.com/awejofficial/DSA)

## Introduction

This repository contains my solutions to Data Structures and Algorithms (DSA) problems from platforms like LeetCode and HackerRank, implemented in Java. It is primarily focused on the [NeetCode 150](https://neetcode.io/) list to build strong problem-solving and logic-building skills.

The solutions are automatically synced, documenting a journey through mastering core computer science concepts. This collection is a resource for anyone preparing for technical interviews, studying DSA, or exploring different approaches to algorithmic problems in Java.

## Getting Started

To explore the solutions, clone the repository and navigate through the directories.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/awejofficial/DSA.git
    ```

2.  **Navigate into the project directory:**
    ```bash
    cd DSA
    ```

3.  **Explore the solutions:**
    Each problem folder is self-contained. You can read the problem description in the `README.md` and review the corresponding `*.java` file for the solution.
